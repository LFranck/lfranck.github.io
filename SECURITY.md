# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité dans ce dépôt, merci de la signaler
en privé plutôt que d'ouvrir une issue publique.

Utilisez le signalement privé de GitHub : onglet **Security** →
**Report a vulnerability**.

Merci d'indiquer :
- la page ou le fichier concerné,
- les étapes pour reproduire le problème,
- l'impact potentiel.

Merci de ne pas publier de détails sur la faille avant qu'un correctif soit disponible.

## Périmètre

Ce dépôt héberge un site statique servi par GitHub Pages (pages HTML/JS,
sans backend). Les problèmes liés à des services tiers (GitHub,
Google Analytics, CDN) sont à signaler directement à ces fournisseurs.
